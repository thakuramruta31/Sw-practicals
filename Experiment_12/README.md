# Student Task Manager

## Project Description
Student Task Manager is a simple Python console application that helps students organize and track their tasks.

## Features
- Add a task.
- View all tasks.
- Mark a task as completed.
- Delete a task.
- Reject empty task titles.
- Handle invalid menu choices and task numbers.
- Display a message when a task is already completed.

## How to Run
Open a terminal in the project folder and execute:

`python app.py`

## How to Run Automated Tests
Install pytest if required:

`python -m pip install pytest`

Run the tests:

`python -m pytest test_app.py -v`

## Storage
Tasks are stored in memory. They are lost when the application exits.
