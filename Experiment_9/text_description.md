# Online Library Management System

The system manages users, books, and book borrowing.

1. Each user has a unique user ID, name, and email address.
2. Each book has a unique book ID, title, author, and availability status.
3. A user can borrow multiple books over time.
4. A book can be borrowed by different users at different times, but it can have only one active borrower at a time.
5. Each borrowing record stores a unique borrowing ID, the user ID, the book ID, borrowing date, return date, and status.
6. A borrowing record belongs to one user and one book.
