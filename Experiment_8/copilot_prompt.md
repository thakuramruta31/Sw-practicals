# Prompt for GitHub Copilot

I am performing a software engineering practical on converting SRS requirements into user stories.

Read the following requirements from my Online Library Management System.

Convert every functional requirement into one or more user stories using this format:

"As a [type of user], I want [feature], so that [benefit]."

For every user story, provide:
1. A unique user story ID.
2. A title.
3. The original SRS requirement ID.
4. Acceptance criteria in Given-When-Then format.
5. Positive and negative test scenarios wherever relevant.

Also perform these tasks:

1. Cover all five functional requirements: FR1, FR2, FR3, FR4, and FR5.
2. Consider the non-functional requirement NFR1.
3. Create a traceability table mapping each SRS requirement to its user stories.
4. Identify missing information, unclear requirements, and assumptions.
5. Evaluate completeness based on requirement coverage, clarity, testability, and traceability.
6. List improvements needed in the generated stories.
7. Do not invent unsupported requirements. Clearly identify any details that need confirmation.

Present the output using headings, bullet points, and Markdown tables.
